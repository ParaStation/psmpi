All `io_done` calls of pscom request are independent of `global_mutex`
of MPICH. All pscom functions could be called with and without a 
`global_mutex` lock of MPICH. If the pscom function call could block 
(e.g., `pscom_wait()`) the progress and lead to deadlock, the global
MPICH lock should be released beforehand (like `MPID_PSP_LOCKFREE_CALL`).
Note that the MPICH global lock is used when `psp` device is configured
based on current configuration setup.

List of `io_done` functions from `libpscom` can be called at any time
(with and without MPICH global lock!):

 * void cb_io_done_init_msg(pscom_request_t *req)
   during MPI initialization only one thread is used ->
   mt safe

 * void sendrequest_done(pscom_request_t *preq)
   mt safe

 * void sendrequest_common_done(pscom_request_t *preq)
   mt safe

 * void cb_io_done_ack(pscom_request_t *request)
   mt safe

 * from pscom_request_t *MPID_do_recv_forward_to(void (*io_done)(), pscom_header_net_t *hnet)

   * void MPID_do_recv_cancel_data_request_ack(pscom_request_t *cancel_req)

   * void MPID_do_recv_rma_lock_exclusive_req(pscom_request_t *req)
     ToDo: mt safe?

   * void MPID_do_recv_rma_lock_shared_req(pscom_request_t *req)

 * void receive_done(pscom_request_t *request)
   mt safe

 * void receive_done_noncontig(pscom_request_t *request)
   mt safe

 * void rma_put_done(pscom_request_t *req)
   add RMA window lock to protect req->user->put_send.win_ptr->rma_local_complete_rank/rma_local_complete_cnt

 * void rma_put_receive_done(pscom_request_t *req)
   add RMA window lock to protect xhead_rma->win_ptr->rma_target_total_received/rma_source_rank_received

 * void rma_accumulate_done(pscom_request_t *req)
   add RMA window lock to protect req->user->accumulate_send.win_ptr->rma_local_complete_rank/rma_local_complete_cnt

 * void rma_accumulate_receive_done(pscom_request_t *req)
   add RMA window lock to protect win_ptr->rma_target_total_received/rma_source_rank_received

 * void io_done_rma_get_answer(pscom_request_t *request)
   add RMA window lock to protect ga->win_ptr->rma_local_complete_rank/rma_local_complete_cnt

 * void io_done_get_answer_send(pscom_request_t *req)
   mt safe

 * void io_done_get_answer_recv(pscom_request_t *req)
   mt safe

 * all RMA callbacks used by pscom RMA interface at origin and target 
   protected by RMA window lock, mt safe
